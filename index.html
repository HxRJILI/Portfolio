Mcovery — AI layer for a consulting firm's rebranding platform

Rebranding a deck was fully manual: open every slide, pick a layout, retype, redraw charts. I built the multi-agent pipeline that restructures any PowerPoint into an on-brand, editable deck inside the client's layout library.

  • Designed four prompt-engineered GPT-4o agents (strategy, layout, business-case strategy, business-case layout) connected by strict JSON contracts, with quality gates and tiered fallbacks.
  • Automated layout definition (OOXML parsing, LibreOffice rendering, GPT-4o vision) with a human-validation checkpoint: 98% acceptance on 120+ layouts.
  • Added RAG over a vector database so prompt size stays bounded as the catalogue grows, and parallelised rendering to remove the main latency bottleneck.
  • Tested on 10 full decks (15–35 slides): zero content loss and anti-repetition rules held; 10–30-slide decks rebranded in about 10–45 s.
  • Measured a vision-based slide-description step, found no reliable gain for its cost, and dropped it. Integrated through an API-level contract.
